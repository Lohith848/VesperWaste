# Vesper Waste

> *Nothing here asks anything of you.*

A cinematic, browser-based 3D desert exploration experience inspired by **Dune**, **Journey**, and atmospheric science-fiction worlds.

Built entirely with **Three.js** and procedural generation, Vesper Waste creates a vast desert landscape featuring monumental ruins, dynamic lighting, drifting sand, immersive ambience, and seamless free-flight exploration—all contained in a single HTML file.

---

- Infinite-style desert terrain
- Fractal noise height generation

# World Generation

The world is generated procedurally using:

- Fractal Brownian Motion (fBm)
- Value Noise
- Height blending
- Terrain smoothing
- Procedural landmark placement

Every landmark is positioned algorithmically.
